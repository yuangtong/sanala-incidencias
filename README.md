# Señala · Portal de incidencias de la facultad

Proyecto del **Laboratorio 5 — Producto informático**.

Plataforma web para que los estudiantes reporten incidencias de la facultad (con evidencia, de forma pública o privada, con opción de anonimato) y un administrador las gestione hasta resolverlas. Inspirada en Zendesk y Stack Overflow.
